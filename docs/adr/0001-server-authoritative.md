# 0001 - 服务端权威判定（客户端零写路径）

H5 游戏客户端可被完全逆向与篡改（改内存、改协议包、重放请求），若客户端持有任何游戏状态写路径——本地判定消除、本地计分、本地计时——作弊者可直接获利且结算不可信。因此决定：全部规则判定（交换合法性、连线检测、连锁结算、计分、回合流转、胜负）在 Go 服务端完成；棋盘、分数、计时的唯一权威源是服务端；客户端仅提交玩家意图（Swap 请求）并渲染服务端下发的事件，不存在任何可绕过服务端的写路径。

## Considered Options

- **客户端权威 + 服务端事后校验**：延迟最低，但客户端作弊即权威，校验形同虚设。否决。
- **双端同时判定 + 服务端仲裁**：表现流畅，但需维护两套语义一致的判定器，状态分叉是必然的长期 bug 源。否决。

## Consequences

- 每次操作的生效延迟受网络 RTT 影响；表现层可做乐观动画（预测回弹/消除），但任何与服务端结果不一致的本地表现必须以服务端事件为准回滚。
- 服务端必须完整实现消除算法（含重力下落、连锁），是本项目核心复杂度所在。
- 回合 10 秒窗口以服务端时钟为权威；客户端倒计时仅作视觉近似。
- 防作弊能力是架构副产品而非附加功能。
